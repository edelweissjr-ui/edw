# Vídeos de apresentação do Torque

- `torque-apresentacao-16x9.mp4`: 30 s, 1920×1080, para YouTube, site, WhatsApp e apresentações.
- `torque-apresentacao-9x16.mp4`: 30 s, 1080×1920, para Reels, Stories, TikTok e Status do WhatsApp.
- Sem áudio: adicione uma trilha no Instagram, CapCut ou Canva.

Roteiro: logomarca → "Sua clínica de fisioterapia inteira em um só sistema" → Agenda → Prontuário → Finanças → CRM → "E muito mais" → convite para a demonstração (torque-saude-demo.vercel.app, admin/admin).

Para editar: `fonte/video.html` contém textos e tempos; `node fonte/render.js h full` (ou `v full`) gera os quadros, e o ffmpeg monta o MP4.
