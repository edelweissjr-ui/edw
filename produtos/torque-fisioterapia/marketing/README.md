# Vídeos de apresentação do Kinesis

- `kinesis-apresentacao-16x9.mp4`: 30 s, 1920×1080, para YouTube, site, WhatsApp e apresentações.
- `kinesis-apresentacao-9x16.mp4`: 30 s, 1080×1920, para Reels, Stories, TikTok e Status do WhatsApp.
- Sem áudio: adicione uma trilha no Instagram, CapCut ou Canva.

Roteiro: logomarca Kinesis → "Sua clínica de fisioterapia inteira em um só sistema" → Agenda → Prontuário → Finanças → CRM → "E muito mais" → logomarca com o convite "Teste grátis agora" (sem link nem login).

Para editar: `fonte/video.html` contém textos e tempos; `node fonte/render.js h full` (ou `v full`) gera os quadros, e o ffmpeg monta o MP4.
